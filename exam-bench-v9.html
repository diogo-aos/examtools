               { "text": "None of the others.", "correct": false, "fixed": true } ],
  "notes": "author-only, never printed" }
  • score.wrong_discounts — a wrong answer costs penalty points (default: points × defaults.penalty_fraction)
  • score.penalty_per_option — on a multiple question, charge the penalty for each wrong option marked instead of once; the ZipGrade key then lists every combination of options with its points
  • tags — lowercase, namespace:value. Questions sharing a group's tag, or a tag ticked in Versions → "Keep together by tag", are never separated
  • groups[].symbol — optional mark (e.g. ★) exported as group_symbol on every member, for the template to append to the question
  • fixed — choice keeps its place (last) when choices are shuffled; "None of the others/above" is fixed automatically
  • open questions have answer_lines, expected_answer, rubric and no choices; they are not on the ZipGrade sheet
  • Full reference: exam-bank-spec.md
PAPER · PREVIEW
Versions

"Shuffle questions & groups" reorders standalone questions and bound blocks relative to each other — a block always stays together. "Shuffle within groups" additionally reorders the questions inside each block (unless the group says "order": "fixed"). Choices marked fixed (e.g. "None of the others") stay last.

KEEP TOGETHER BY TAG

Questions that share a ticked tag are never separated (🔒 = already bound by a bank group). Only tags shared by two or more ready questions are listed.

Same seed always rebuilds the same versions.
